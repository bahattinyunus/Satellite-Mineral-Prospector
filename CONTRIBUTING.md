# Katkıda Bulunma Rehberi

Satellite Mineral Prospector projesine katkıda bulunmak istediğiniz için teşekkür ederiz!

## Nasıl Katkı Sağlayabilirsiniz?

1.  **Hata Bildirimi (Bug Report)**: Karşılaştığınız sorunları detaylı bir şekilde GitHub Issues üzerinden bildirin.
2.  **Özellik İsteği (Feature Request)**: Yeni özellik önerilerinizi tartışmaya açın.
3.  **Pull Request (PR)**:
    *   Projeyi Fork'layın.
    *   Yeni bir özellik dalı (feature branch) oluşturun (`git checkout -b ozellik/yeni-ozellik`).
    *   Değişikliklerinizi yapın ve testleri çalıştırın (`pytest`).
    *   Kodunuzu gönderin (`git push origin ozellik/yeni-ozellik`).
    *   Bir Pull Request açın.

## Kod Standartları

*   **Temiz Kod**: Değişken ve fonksiyon isimlendirmelerinde açıklayıcı olun.
*   **Tip Belirleme (Type Hinting)**: Tüm fonksiyonlarda Python type hinting kullanın.
*   **Testler**: Yeni özellikler için mutlaka birim testleri ekleyin.
